# Website audit — 12 October 2026

## Corrections

- Assignment deadline defaults and minimum values used UTC strings in local-time inputs. In India they appeared 5 hours 30 minutes early. Use a shared local-time formatter for assignments, attendance and scheduled publishing.
- Scheduled publishing used today's timezone offset for future dates. The shared formatter uses the offset at the selected date, preserving scheduled times across daylight-saving transitions.
- Updated proxy-addr from 2.0.7 to 2.0.8 and source-map-js from 1.2.1 to 1.2.2 for the dependency advisories reported by npm audit. No major dependency upgrade was needed.

## Validation

- 59 automated tests passed. New scheduling regression covers India, New York winter/summer, UTC, invalid input and timestamp round trips.
- Production build and TypeScript check passed. Dependency audit reports zero known vulnerabilities after the updates.
- Isolated 200-account classroom test passed: 500 sign-in page/OTP requests and 3,400 workspace requests, including content, attendance, search, progress and PDF ranges. This is local SQLite/test-OTP evidence, not production capacity certification.
- Browser checks covered all ten teacher navigation pages and all eight student navigation pages using local fixtures. No application console errors were recorded.
- Verified the corrected assignment deadline default/minimum in the local browser, created a local test assignment, and confirmed it appeared in the student interface.
- Student overview had no horizontal overflow at phone, tablet and desktop viewport settings: 390 × 844, 820 × 1180 and 1440 × 900.
- Live homepage, catalogue, guest folder navigation and PDF opening/page navigation/zoom worked. Health, catalogue, explore, anonymous session, robots.txt and sitemap.xml returned HTTP 200 in read-only probes.

## Limits

Production records and account permissions were not modified. Physical-device GPS/permission prompts, real provider email/SMS delivery, external Google sign-in and sustained production concurrency were not exercised. Authentication adapters, access rules, upload validation, attendance constraints and Excel workbook validity are covered by the automated suite. Browser viewport checks do not substitute for every physical device.
